# ระบบบันทึกและติดตามภารกิจ (JobComm RTAF)
### แผนกสื่อสาร หน่วยบัญชาการอากาศโยธิน (อย.) กองทัพอากาศ

เว็บแอปพลิเคชันสำหรับบันทึก ติดตาม และแสดงผลภารกิจของแผนกสื่อสาร หน่วยบัญชาการอากาศโยธิน พัฒนาตรงตามแบบร่าง (Wireframe) พร้อมรองรับการแสดงผล 3 อุปกรณ์หลัก:
1. 📱 **โทรศัพท์มือถือ (Mobile Responsive)** - ใช้งานง่าย มี Drawer เมนูด้านข้าง บันทึกภารกิจได้รวดเร็ว
2. 📺 **จอทีวี (TV Digital Signage Mode)** - แสดงผลสถานะภารกิจสดแบบ Fullscreen นาฬิกาดิจิทัลขนาดใหญ่ ตัวอักษรคมชัดมองเห็นได้ระยะไกล พร้อมอัปเดตข้อมูลแบบเรียลไทม์ (SSE)
3. 💻 **จอคอมพิวเตอร์ (Desktop PC)** - ตารางสรุปภารกิจ ค้นหา กรองข้อมูล ส่งออกไฟล์ Excel/CSV และพิมพ์รายงานคำสั่งการทางการทหาร

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide Icons
- **Backend**: Node.js, Express.js (REST API + Server-Sent Events สำหรับ Real-time Sync)
- **Database**: SQLite (Node.js 22 Built-in Native SQLite) - เสถียร ไม่ต้องติดตั้งฐานข้อมูลภายนอก ข้อมูลถูกจัดเก็บในไฟล์ `server/database.sqlite`

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: รันคำสั่งเดียว (Single Command)
เปิด PowerShell หรือ Command Prompt ที่โฟลเดอร์โปรเจกต์:
```powershell

```
ระบบจะเริ่มทำงานที่: **http://localhost:5000**

## 📋 ฟังก์ชันการทำงานตามแบบร่าง (Wireframe Features)
1. **หน้าเพิ่มข้อมูลภารกิจ (Add Mission)**:
   - บันทึกชื่อภารกิจ (ประชุม, ซ่อมบำรุง, วางสายสัญญาณ, วิทยุสื่อสาร ฯลฯ)
   - เลือกวันที่เริ่มต้น - สิ้นสุด (พร้อมแปลงเป็นรูปแบบ พ.ศ. อัตโนมัติ เช่น 1 ต.ค.69)
   - ระบุเวลาเริ่มต้น - สิ้นสุด
   - ระบุสถานที่ (มีปุ่มลัดเลือกสถานที่สำคัญของ อย.)
   - ระบุรายละเอียดภารกิจ ผู้รับผิดชอบ และระดับความสำคัญ
   - ปุ่ม "บันทึก" บันทึกข้อมูลลงฐานข้อมูล SQLite ทันที

2. **หน้าภารกิจวันนี้ (Today's Missions)**:
   - แสดงหัวข้อวันปัจจุบัน (เช่น `ภารกิจวันนี้ 1 ต.ค.69`)
   - การ์ดภารกิจพร้อมเวลานับถอยหลังอัตโนมัติ (`ในอีก ... ชม.` / `ในอีก ... นาที` / `กำลังดำเนินการ` / `เสร็จสิ้นแล้ว`)
   - ปุ่มเปลี่ยนสถานะด่วนเป็น "เสร็จสิ้น" หรือ "เริ่มงาน"
   - ช่องค้นหาและตัวกรองตามสถานะงาน

3. **หน้าวันอื่นๆ (Other Days)**:
   - ตรวจสอบภารกิจล่วงหน้าและย้อนหลัง
   - เลือกระบุวันที่เจาะจงได้

4. **ระบบ Real-time Live Sync**:
   - เมื่อมีการบันทึกภารกิจใหม่จากมือถือ หน้าจอทีวีและคอมพิวเตอร์จะอัปเดตข้อมูลขึ้นจอทันทีโดยไม่ต้องกดรีเฟรช
